Saru さる

Read Japanese books on paper: photograph a page, circle a word with your finger, look it up in a full offline dictionary, and add it to AnkiDroid in one tap.

Help

  • Cards don't get added. Install AnkiDroid, open it once, then allow Saru to use it when asked. Cards go to the deck set in Saru's settings, which is created with the first card.
  • A word is misread. The text Saru read appears in the search box: correct it there and the results update. Sharp, well-lit photos read best.
  • Small print is hard to circle. Swipe along the line instead, or switch to Crop and select the passage.
